pandas : Series et DataFrame (exercices)

Pour chaque exercice : complète les cellules marquées # TODO, exécute-les et compare avec le résultat attendu. Ne regarde la solution qu’après avoir vraiment essayé !

On travaille sur les livraisons d’un petit entrepôt.

import pandas as pd

1. Créer une Series

Crée une Series stocks qui contient les quantités [120, 35, 0, 80], avec pour index les articles "vis", "écrou", "clou", "rondelle", et nommée "stock". Affiche ensuite le stock de clous en utilisant son étiquette.

# TODO

# Résultat attendu :
# 0
💡 Solution 
stocks = pd.Series(
    [120, 35, 0, 80],
    index=["vis", "écrou", "clou", "rondelle"],
    name="stock",
)
print(stocks["clou"])

3. Des index qui ne s’alignent pas

Sans exécuter le code, devine ce qu’affiche la cellule suivante, puis vérifie.

semaine_1 = pd.Series([5, 8, 2], index=["vis", "écrou", "clou"])
semaine_2 = pd.Series([3, 4], index=["clou", "vis"])

print(semaine_1 + semaine_2)

✍️ Ta prédiction :

  • valeur pour vis :
  • valeur pour écrou :
  • valeur pour clou :
💡 Solution 
# clou      5.0    ← 2 + 3
# vis       9.0    ← 5 + 4
# écrou     NaN    ← absent de semaine_2
# dtype: float64
#
# pandas additionne les valeurs qui ont la même étiquette, pas la même position.
# "écrou" n'existe que dans semaine_1 : le résultat est NaN (donnée manquante),
# et toutes les valeurs passent en float, car NaN est un float.

8. axis=0 ou axis=1 ?

Voici les colis expédiés par trois entrepôts sur trois mois.

  1. Calcule le total de chaque mois (une valeur par colonne).
  2. Calcule le total de chaque entrepôt sur le trimestre (une valeur par ligne).
expeditions = pd.DataFrame(
    {"janv": [100, 80, 60], "fev": [120, 70, 65], "mars": [90, 85, 70]},
    index=["Lille", "Lyon", "Nantes"],
)

# TODO

# Résultat attendu :
# janv    240
# fev     255
# mars    245
# dtype: int64
# Lille     310
# Lyon      235
# Nantes    195
# dtype: int64
💡 Solution 
print(expeditions.sum(axis=0))   # on « écrase » les lignes : une valeur par colonne
print(expeditions.sum(axis=1))   # on « écrase » les colonnes : une valeur par ligne

🤔 Ici, additionner les colonnes a un sens métier : ce sont trois mesures de même nature (des colis par mois).

9. loc et iloc

Avec le DataFrame expeditions :

  1. affiche les expéditions de l’entrepôt de Lyon en utilisant son étiquette ;
  2. affiche la valeur de la dernière ligne, colonne mars, en utilisant les positions.
# TODO

# Résultat attendu :
# janv    80
# fev     70
# mars    85
# Name: Lyon, dtype: int64
# 70
💡 Solution 
print(expeditions.loc["Lyon"])

10. Chasse au bug : la colonne qui disparaît

Ce code doit ajouter une colonne poids_moyen (poids par colis), puis l’afficher. Il plante avec une KeyError. Pourquoi ? Corrige-le.

livraisons.assign(poids_moyen=livraisons["poids_kg"] / livraisons["colis"])
print(livraisons["poids_moyen"].round(2))

# Résultat attendu après correction :
# 0    2.54
# 1    1.60
# 2    1.78
# 3    3.05
# 4    1.50
# Name: poids_moyen, dtype: float64
💡 Solution 
# assign() ne modifie pas le DataFrame : il en RENVOIE un nouveau.
# Le résultat n'était stocké nulle part, la colonne n'existe donc pas dans livraisons.
livraisons = livraisons.assign(poids_moyen=livraisons["poids_kg"] / livraisons["colis"])
print(livraisons["poids_moyen"].round(2))

11. Pour aller plus loin : quel transporteur charge le plus ?

À partir de livraisons, affiche le poids moyen par colis le plus élevé, puis le nom du transporteur de cette livraison.

Indice : .max() donne la valeur maximale, et .idxmax() donne l’étiquette de la ligne où elle se trouve.

# TODO

# Résultat attendu :
# 3.05
# Fretex
💡 Solution 
plus_lourd = livraisons["poids_moyen"].max()
ligne = livraisons["poids_moyen"].idxmax()
print(round(plus_lourd, 2))
print(livraisons.loc[ligne, "transporteur"])
